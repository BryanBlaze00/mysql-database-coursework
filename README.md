# 🗄️ MySQL Database & Procedural SQL Coursework

This repository tracks my database development progress, complex queries, and procedural SQL implementations built in MySQL for my database coursework.

## 📌 Topics Covered
- **Data Querying & Manipulation:** Multi-table JOINs, subqueries, aggregate grouping, and analytical scripts.
- **Procedural Programming:** Stored Procedures, Stored Functions, and Triggers utilizing control structures (`IF`, `CASE`, `WHILE` loops).
- **Database Objects:** Views, Indexes, and Schema definition scripts.

## 🛠️ Environment & Tools
- **RDBMS:** MySQL Server 8.0
- **Database Tools:** MySQL Workbench / VS Code
- **Version Control:** Git & GitHub

## 📂 Repository Structure
- `01-schema-setup/` — Database DDL scripts and table creation scripts.
- `02-queries-and-selects/` — Data retrieval scripts and query optimization exercises.
- `03-stored-programs/` — Stored procedures, user-defined functions, and automated triggers.
- `04-assignments/` — Turned in assignements.
